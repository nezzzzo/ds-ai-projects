# Synthetic Lean-Body-Mass Workout Dataset

## 1. Overview
This dataset contains **20 000 synthetic observations** for experimenting with predictive models of **lean-body-mass (LBM) change** over a workout program.

| File | Rows × Columns | Size |
|------|---------------|------|
| **`lbm_dataset.csv`** | 20 000 × 16 | ~2 MB |


## 2. Columns

| Column | Type | Unit / Scale | Description |
|--------|------|--------------|-------------|
| **Age (years)** | `int` | years | Chronological age at program start (18 – 65 y). |
| **Sex** | `category` | — | `"Male"` or `"Female"`. |
| **Height (cm)** | `float` | cm | Standing height. |
| **Initial LBM (kg)** | `float` | kg | Baseline lean-body-mass before training. |
| **Training Experience (years)** | `float` | years | Cumulative resistance-training experience. |
| **Training Frequency (sessions per week)** | `int` | sessions/wk | Planned weekly sessions (1 – 7). |
| **Average Reps per Set** | `int` | reps | Mean reps across major lifts. |
| **Average Load per Exercise (kg)** | `float` | kg | Mean external load per exercise. |
| **Average Daily Calories (kcal)** | `int` | kcal/day | Habitual energy intake. |
| **Average Daily Protein Intake (grams)** | `int` | g/day | Dietary protein consumed. |
| **Average Sleep Duration per Night (hours)** | `float` | h/night | Self-reported nightly sleep length. |
| **Sleep Quality (1–10 scale)** | `float` | 1 – 10 | Subjective sleep quality (higher = better). |
| **Stress Level (1–10 scale)** | `float` | 1 – 10 | Subjective stress (higher = more stressed). |
| **Creatine Supplement Use** | `category` | — | `"Yes"` if creatine taken, else `"No"`. |
| **Training Duration (Weeks)** | `int` | weeks | Length of the tracked program (4 – 52 wk). |
| **LBM after the training period (kg)** | `float` | kg | **Target** – post-program LBM. |
